# UnderShine

도시의 빛과 일상 사이, 나다운 선을 발견하는 컨템포러리 패션 브랜드 웹사이트입니다.

## 구성

- 순수 HTML / CSS / JavaScript
- 반응형 모바일 내비게이션
- 홈, 소개, 제품, 이야기, 연락하기 섹션

제품 정보는 `products.json`에서 관리합니다. 제품을 추가하거나 수정하면 홈과 제품 페이지에 함께 반영됩니다.

JSON 데이터를 불러오므로 로컬에서는 간단한 웹 서버로 확인해야 합니다. 프로젝트 폴더에서 `python3 -m http.server`를 실행한 뒤 브라우저에서 표시된 주소를 여세요.
